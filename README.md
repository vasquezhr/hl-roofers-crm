# H & L Roofers CRM

A small, self-hosted CRM for H & L Roofers, a roofing business in Virginia. It borrows Salesforce Field Service ideas (accounts, opportunities, jobs, crews, profiles) in a form the owners and crews can learn quickly.

| Folder | What is in it |
| --- | --- |
| `app/` | The real app: Python, Django, PostgreSQL and Bootstrap. Phase 1 (customer records and search) is built. Start with `app/README.md` |
| `mockup/` | The clickable mockup of all four phases: one HTML file that opens in any browser |
| `docs/` | The plan, the decisions made so far, and what the business's notes and files look like (counts only) |

Real customer data never goes in this repository.
